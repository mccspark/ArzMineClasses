# ArzMineClasses

Система классов для сервера ArzMine: Фермер, Шахтёр, Кузнец, Лесоруб и Мистик.
Прокачивай уровни, открывай навыки в дереве, выбирай подкласс, улучшай снаряжение заточкой и редкостью.

## Требования
- Minecraft 26.2, Fabric Loader, Fabric API
- Trinkets
- Farmer's Delight (для механик Фермера) — [уточни, обязателен или нет]
- LuckPerms (опционально, для групп по классам)

## Установка
Положи jar в папку `mods` клиента и сервера.

## Для разработчиков
```groovy
repositories { maven { url "https://jitpack.io" } }
dependencies { implementation "com.github.mccspark:ArzMineClasses:<тег>" }
```
